# AGENTS

Always read, in order:

1. HANDOFF.md
2. DECISIONS.md
3. ROADMAP.md
4. BUILD-STATE.md

Core principles:

- Knowledge is a first-class artifact.
- Code is one output of engineering.
- Research before design.
- Ontology before implementation when semantics change.
- Mandatory impact analysis before implementation.
- Skills are composable.
- Workflows orchestrate skills.
- Every important assertion must be traceable to evidence.
- Keep current-state and proposed-state separate.
- Update BUILD-STATE.md after every delivery.
