# Project Handoff

## Vision

Create an Engineering Operating System for AI coding agents.

The goal is not a giant prompt.

The goal is a modular repository containing:

- shared engineering policies
- reusable skills
- orchestrated workflows
- ontology engineering
- impact analysis
- architecture review
- implementation guidance
- verification
- knowledge evolution

## Initial scope

First deliver the repository blueprint, not all skills.

## Existing prototypes

Three prototype skills already exist externally:

- reconstruct-system-knowledge
- ontology-driven-development
- principal-engineering

Treat them as inputs, not final designs.

## Guiding idea

Every change should improve:

- implementation
- ontology
- engineering model
- specifications
- traceability
- organizational knowledge
