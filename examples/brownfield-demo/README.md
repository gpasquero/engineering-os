# brownfield-demo

**A tiny, fake Brownfield repository, bundled so the documented onboarding path
works from a clean clone with no external system.**

It is deliberately small and deliberately imperfect: two modules, two tables,
two controllers, two test suites and three documents, with a rule stated in
prose that no test enforces. That gap is the point — it is what onboarding is
supposed to surface.

Nothing here is a real product. It exists to be discovered.
