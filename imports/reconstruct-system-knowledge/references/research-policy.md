# External research policy

External research must be evidence-driven and clearly separated from repository behavior.

## Priority order

1. Official standards bodies.
2. Normative protocol specifications.
3. Official vendor documentation.
4. Peer-reviewed research.
5. Recognized reference architectures.
6. Stable industry vocabularies.
7. Existing public ontologies.
8. Authoritative domain glossaries.

## For every source record

- canonical identifier
- title
- issuing organization
- version
- publication date
- retrieval date
- normative status
- relevant concepts
- possible mappings
- incompatibilities
- licensing considerations

## Always distinguish

- external standard says
- repository specifies
- code implements
- tests enforce
- recommended alignment

External sources may clarify or challenge the model, but they must not silently overwrite observed repository behavior.
