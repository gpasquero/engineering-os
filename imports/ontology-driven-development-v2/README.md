# ontology-driven-development

An ontology-driven development skill for features, bugs, behavior changes, integrations, and refactoring.

The workflow includes a mandatory pre-implementation and post-implementation change impact analysis.

## Install globally

Copy this directory to:

```text
~/.claude/skills/ontology-driven-development/
```

## Install in a repository

Copy it to:

```text
.claude/skills/ontology-driven-development/
```

## Usage

```text
/ontology-driven-development add OAuth Device Flow
```

```text
/ontology-driven-development fix duplicate execution events
```

```text
/ontology-driven-development change ToolPlugin visibility rules
```

```text
/ontology-driven-development refactor credential resolution without changing behavior
```

The skill expects the repository knowledge model under `model/`, but it can operate with partial artifacts and record missing-model gaps.
