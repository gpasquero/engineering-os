## The diagnosis

**The reviewer's hypothesis was right, and it is now a measurement.**

Initial Acquisition establishes **six** semantic relationships. Continuous
Acquisition preserves **two**.

| Predicate | Meaning | Initial | Continuous |
|---|---|---|---|
| `enforced-at` | an invariant is checked here | ✓ | ✓ |
| `specializes` | a guarantee narrows a rule | ✓ | ✓ |
| `constrains` | an invariant guards **this capability** | ✓ | **✗** |
| `implements` | this artifact realises **this capability** | ✓ | **✗** |
| `validates` | this suite covers **this capability** | ✓ | **✗** |
| `scoped-to` | this capability lives in **this context** | ✓ | **✗** |

**Every one of the four lost predicates attaches something to a Capability** —
and `EQ-06` is the capability question.

Two models of the same repository:

```text
mostly initial     76 nodes   78 edges   1.03 edges/node   all 6 predicates
mostly maintained  94 nodes   36 edges   0.38 edges/node   4 present, 2 in use
```

**More knowledge. Less than half the connections.**

## What was learned

### Coverage had hidden a total turnover

`1/9 → 1/9` was true and the tool printed **"understanding held"**.

The question answered at `t0` degraded at `t1` and never returned. A different
question became answerable later. **Coverage netted the two to zero and called it
stability.**

```text
Understanding Retention  0%   of 1 answered at t0: 0 retained, 1 degraded, 1 gained
```

The verdict line now reads **"understanding did not survive"** on exactly the
same run and the same data. Nothing about the system changed; the instrument did.

> **A level can be constant while everything underneath it turns over, and the
> turnover is the part a customer feels.**

### The metric had to be built adversarially against its own obvious form

The first sketch counted a gain as retention. That version scores this run at
**100 %** — a system that forgets everything it knew and learns something else
would have looked perfect.

**That is the same substitution coverage had already made**, one level down. It
was avoided only because the reviewer's phrasing — *"for each question that was
previously answerable"* — fixes the denominator, and the denominator is the whole
metric.

### The defect survived because of the question that was asked of it

Continuous Acquisition was always tested by *did it propose the changed things?*
**It always did** — 4 proposals for a 1-suite change, 0 when nothing changed,
13 % maintenance cost across the history. Every one of those numbers is good.

**It was never asked whether what it proposed still meant anything.**

The reviewer's reframing is precisely this: *what may it infer* is answerable by
inspection, and *what understanding must it preserve* is answerable only by
measurement.

### The fix will add no knowledge at all

None of the four missing predicates requires inference. Each is established by a
rule that already exists, from evidence the mechanical delta already carries.
**They were not inferred at `t0` either — they were read.**

So the fix proposes **zero new entities** and should move two questions. Under
the framing this project used until two sessions ago, that would have looked like
a change that did nothing — which is the first concrete case of `ADR-0127`, and
it arrived one session after the distinction was drawn.

### Acceptance is now a number stated in advance

`EQ-06` must be `answered` at `t9`, and retention must be **100 %**, on frozen
commits, against a recorded baseline.

**This is the first time in forty-eight sessions that the next piece of work has
a falsifiable acceptance criterion written before the work starts.**
