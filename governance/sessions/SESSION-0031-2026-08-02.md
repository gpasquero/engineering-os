## Decisions made

**`ADR-0088` — the query result contract.** Seven defects, all of the same kind:
**each produced a plausible answer that was wrong.**

1. **Path provenance.** A row recorded one `via` — the first predicate — which
   for a multi-hop answer reports the first edge as if it explained the whole
   dependency. Rows now carry the **complete ordered path**: every edge, its
   direction, and the reason it matched.
2. **Edge output** returned the induced subgraph between result nodes, so an
   answer was explained with edges the query never followed. It now returns what
   the traversal walked; `induced-subgraph` is a separate, explicit mode.
3. **Parallel edges.** `with` matched an edge and then looked up an *arbitrary*
   edge between the same two nodes to report it. It now evaluates the edge in
   hand.
4. **Declaration validation.** A schema over operators, fields, directions, hop
   limits, output modes and referenced types. **An unknown field fails.**
5. **Applicability.** Four statuses — `ok`, `empty`, `not-applicable`, `invalid`.
   An empty result never hides an applicability error.
6. **Determinism and limits.** Cycles visit once, equal-length paths break
   lexicographically, depth 16, results 1000, and **truncation emits a
   diagnostic**.
7. **Parity** compares status, rows, paths, ordering, edges and diagnostics.

## What was learned

### The parity check found a real divergence the moment it got teeth

Comparing only identifiers, both engines had agreed on 334 pairs. Comparing
**ordering**, they did not.

**JavaScript's `localeCompare` is locale-aware and does not order like Python's
codepoint comparison.** `ADR.004` sorts before `Actor.Customer` by codepoint and
after it by locale. Same rows, different order, in a contract that declares
ordering deterministic.

Nothing in the shared query declarations was wrong. The defect was entirely in
the assumption that "sort by id" means the same thing in two languages —
**exactly the class of bug two engines produce, and exactly why `ADR-0086`
recorded the risk instead of dismissing it.**

### Two of the seven defects were invisible by construction

Path provenance and induced-subgraph output both produced output that *looked*
right. A single `via` on a two-hop path is a well-formed field with a plausible
value; an induced subgraph is a valid set of edges. **Neither would ever have
been caught by a test asserting shape.**

They were found by reading the semantics against what the answer claims to mean —
which is the argument for hardening a contract *before* a real system depends on
it rather than after.

### A schema that only accepts is not a schema

`tools/check-query-schema.py` feeds 12 malformed declarations to the validator
and requires each to be rejected with a specific message. **A schema is only
useful in proportion to what it refuses**, and nothing else in this repository
tests refusal at the declaration level.

### The fixture had to be built to have the defect

`tests/projects/parallel-edges` exists because no existing fixture had two
predicates between one pair of nodes — so the parallel-edge bug could not fire
anywhere. **The corpus had been accidentally shaped to avoid its own worst case**,
which is the normal condition of a hand-written fixture set.
