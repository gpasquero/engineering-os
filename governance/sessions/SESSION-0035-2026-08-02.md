## Decisions made

**`ADR-0095` — the architecture is the engineering loop.** Ten stages, five of
which exist. **Every stage before Execution is deterministic**; a language model
enters at Execution and nowhere earlier.

It also makes domain independence a test rather than an aspiration: **every new
external system should require adding knowledge, never changing reasoning.** A
system that forces a reasoning change opens an investigation into the abstraction
before any extension.

node declares an objective, dependencies, completion conditions, evidence

## What was learned

### The largest transfer of judgement so far

An executor now receives a task with an objective, its dependencies, a completion
condition, the evidence it must produce and **no decisions about ordering**.

Sequencing, decomposition, blocking and parallelism were four judgements the
executor previously had to make. All four are now computed — **parallelism from
the dependency graph rather than from an annotation someone maintains.**

### Every graph ends in a task nothing can execute

`T-review-gate` requires `C-approve`, and **no worker of any kind may hold that
capability** — `ADR-0023` prohibits self-certification, and it has since
`SESSION-0011`.

The consequence is that every task graph terminates in a human decision. **That
is correct, and it is the first time a governance rule written for documents has
constrained a runtime artifact.**

### The loop's closure is present as a node and absent as a capability

`T-update-knowledge` appears in every graph. Nothing can execute it: the
capability that decides *what* to record does not exist, only the mechanical half
that writes it.

**Declaring the task anyway was the honest choice.** The graph now says the loop
does not close, in the place where closing it would happen.

### Three intents, and the missing ones are the finding

`I-modify-behavior`, `I-investigate`, `I-audit` are declared. **Add Feature,
Refactor, Migrate, Improve Performance, Improve Security and Remove Capability
are not** — each is a real intent with no plan to select.

Declaring them would produce entries resolving to nothing, which `ADR-0091`
forbids of recommendations for the same reason. `I-investigate` is declared with
**no plan** and makes that gap visible rather than hiding it.

### The metamodel has been unchanged for four milestones

Twenty-three entities have now supported a governance repository, an
API-machinery subsystem, recommendations, plans and task graphs. **Everything
built since has been registries and engines.**

`ADR-0096` is the first decision to write down why: entities are for what belongs
in a model, and sessions, plans, tasks and intents belong to interactions.
