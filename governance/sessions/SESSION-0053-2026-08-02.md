### Repaired

**`tools/_cli.py` — two shared guards, because three failures were one family:**
a tool treating an argument as a project directory without checking it was one.

```text
python tools/compile.py --help        created a directory called `--help`
python tools/test.py --help           crashed with a traceback
python tools/compile.py exmaples/tny  exited 0 and emitted an empty model
```

**The third is the worst thing found in this session.** A new user who mistypes
a path was told compilation succeeded and handed a model with nothing in it.
Both guards are now wired into all twelve documented commands: **`--help` prints
help everywhere, and a missing project is refused rather than created.**

| | |
|---|---|
| `tools/lifecycle.py` stage 5 | failed on **every first run** — the only run a new user makes. It now compiles the maintained model in-process instead of telling the user to go and do it |

## What was learned

### One authoring error, three tools, and a silent success

`compile.py`, `test.py` and `curate.py` each independently treated `argv[1]` as
a path. **None validated it.** The compiler's version was worst because it
*succeeded*: a mistyped path produced a directory, an empty model and exit code
0.

Every check this project owns was passing throughout. **Nothing verifies what a
tool does with an argument it was never given.**

### The lifecycle demo only ever worked on the repository it was written for

`tools/lifecycle.py` is documented in `README.md` §14 as the way to maintain
*your* model after a change. Its curation filter was a list of `ai-desk`
substrings — `Auth`, `Jwt`, `Lockout`, `Ticket`. On the bundled demo it
authorized **2 of 15 proposals** and looked like a broken pipeline.

**A demonstration that hard-codes its own demonstration data is not a
demonstration.** The policy is now an argument; the frozen longitudinal
benchmark keeps its fixed policy deliberately, because a benchmark needs a
constant (`ADR-0129`).

### A committed research artifact had drifted from the code

Re-running the lifecycle changed `D-invariant-without-enforcement` from **10 to
9**: `Invariant.ReturnsTheSameDateFor0Minutes` now carries an enforcement edge,
because `SESSION-0049` taught Continuous Acquisition to preserve `enforced-at`.

**The artifact was committed before that fix and never re-run.** It is an
improvement, not a regression — and it means committed research output can go
stale relative to the code that produced it, silently, with nothing detecting
it.

### Documentation is a test, and it caught more than the test suite did

Thirteen findings, from writing prose. In the same session the suite reported 17
fixtures passing, 20 registries loading and 315 governance records consistent —
**all true, and all compatible with a tool that silently succeeded on a typo.**
