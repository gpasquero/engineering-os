## What was learned

### The criterion inverted the conclusion the previous session was reaching

`SESSION-0025` was heading toward *`Specification` is a suffix applied where no
distinction exists.* That conclusion would have **deleted
`StateMachineSpecification` — the one specification that is real — and kept
`StateMachine`, the empty half.**

Structural similarity can detect that two entities are 1:1. **It cannot say which
of the two should survive.** Independent existence can, and it resolved the
review in two opposite directions: for state machines the Specification survives,
for dimensions the bare name does.

That is the strongest argument yet for `ADR-0069`'s reframing. A count-driven
review would have merged both pairs and been satisfied, having deleted the wrong
half of one of them.

### Classification is not collapse

The obvious move on 64 predicates for 82 rows was to collapse them onto 18 core
types. **That would have destroyed distinctions to improve a metric** —
`Policy.governs` and `Dimension.classifies` are genuinely different.

So the vocabulary is a taxonomy: predicates stay distinct and each declares a
parent. **The predicate count does not fall, and that is the intended outcome.**
What changes is that the ontology can now be queried by category instead of by
sixty-four special cases.

The vocabulary's first act was to resolve the collision that motivated it:
`governs` split into `governs`, `controls-lifecycle-of` and `classifies` — the
tenth term this project has had to split.

### The metamodel became load-bearing

For twenty-five sessions the metamodel was a description of a language nothing
spoke. `tools/compile.py` phase 3 reads `model/metamodel/` to learn which entity
types exist and which predicates are registered, **then rejects a model that
violates them.**

Verified by breaking the example three ways:

```text
[resolve]   FAILED — 3 error(s):
    adr-0001.md: 'resolves' points at unknown node 'Issue.9999'
    concept-order.md: 'Blorp' is not a metamodel entity
    concept-order.md: predicate 'invented-predicate' has no registered parent
```

**This is the difference between a compiler and a converter**, and it is the
first evidence that the metamodel constrains anything.

### Compiling made three decisions visible rather than asserted

- `Invariant.PaymentBeforeShipping` has **no** `enforced-at`. The zero-cardinality
  case `invariant.md` argued for is now a real node with a real gap.
- `WorkflowStep.Checkout.1` holds the position. `ADR-0068` in one node.
- `Artifact.CheckoutService` has an active revision and no state of its own.

Nothing in the pipeline had to be special-cased for any of them. Decisions
written over five sessions composed without adjustment.

### The generated OWL merges cleanly with the metamodel ontology

`examples/tiny/build/model.ttl` imports the metamodel and the union parses at 719
triples with **no instance typed by an undeclared class and no edge using an
undeclared property.** Layers A and B are demonstrably compatible rather than
asserted to be.
