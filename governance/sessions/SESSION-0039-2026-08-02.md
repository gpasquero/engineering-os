# SESSION-0039 — 2026-08-02

## Objective

Build **both halves** of Brownfield onboarding — discovery production and
proposal application — and run the complete slice on `ai-desk`.

## Correction accepted

**`SESSION-0038` overstated its result.** It reported that "no execution
mechanism was built" as the strongest evidence for `ADR-0105`.

> The declarations define **how Discovery is directed.** Discovery Workers
> perform the actual work.

`ADR-0107` records the correction: **orchestration declarations are never
reported as Discovery being built.**

## Decisions made

**`ADR-0107` — discovery production.** Three worker kinds: deterministic
extractors, bounded interpreters that **name their rule**, and gap identifiers
that propose no knowledge. **No language model participates**, so the first
candidate model is reproducible and the deterministic ceiling can be measured.

## Work done

Eight extractors, two bounded interpretation rules, gap identification, the
Candidate Engineering Model with a content digest, the Proposal Applier, the
review tool, support classification, SHACL and index emitters.

**The complete slice, all eleven steps.**

## What was learned

### The honest comparison is the finding

| | grep-based | discovered |
|---|---|---|
| invariants for the OAuth plan | 5 | 7 |
| decisions before the first LLM token | **54** | 51 |

**The KPI went down.** The discovered plan is not straightforwardly better, and
the ways it is not are worth more than a flattering result.

**Discovery wins on coverage and reproducibility.** 28 modules, 161 endpoints, 34
tables, 70 suites, a stable digest. A human reading source does not scale and
does not repeat.

**It loses on abstraction.** A human read eight lockout test cases and wrote
*one* invariant — `Invariant.AccountLockout`. Rule `R1` reads eight test names
and proposes *eight*: `RejectsA7CharPasswordBelowMinimum`,
`RejectsANonStringPasswordTypeConfusio`. **More assertions, worse abstractions.**

**And it missed the most important one.** `TenantIsolation` is stated in ADR
prose; `R1` reads test names. **A bounded rule cannot find what is not where it
looks**, and no rule was written for prose because writing one deterministically
means pattern-matching English.

### That measurement is the point

> **Deterministic extraction is better than a human at coverage and worse at
> abstraction.**

`ADR-0103` permits a probabilistic interpreter and requires the justification to
be genuine. **It is now evidential rather than anticipated**, which is exactly
the ordering that decision asks for: establish what determinism reaches, then
delegate what it cannot.

Building the probabilistic interpreter first would have produced a candidate
model that was not reproducible **and never measured the ceiling.**

### Discovery found things nobody asked it for

**All five ai-desk ADRs are `Proposed`** while the codebase implements them —
recorded as five ambiguities with both readings, not silently resolved.

**`refresh_tokens` carries no tenant column**, in a system whose foundational
decision is tenant isolation. Recorded as a gap: *whether that is correct is
unrecorded.* It may be perfectly correct — a token belongs to an agent and an
agent belongs to a tenant — and the system does not decide.

**Two modules have no test suite.** Reported by the gap identifier, which
proposes no knowledge at all.

### The pipeline found two defects in itself

**The applier's YAML emission was wrong.** Hand-rolled quoting broke on a label
containing `:` and on a value beginning with `@`.

`ADR-0106` predicted this exactly: *writing authoring sources from proposals
means workers shape the repository's text, and the parser's schema is now
load-bearing.* **A generated source is compiler input**, so the fix was to emit
with a YAML writer rather than to escape more carefully.

**`implements` was used directly and was unregistered** — the fourth instance of
a core relationship type used directly rather than specialized.

### The applier refused more than it accepted

25 entities authorized from 315. **342 relationships were refused** because an
endpoint was not accepted — an edge to an unaccepted node would compile to a
dangling reference.

That refusal is the applier working: **a coherent subset is not an arbitrary
one.**

## Recommended next action

**A rule that reads prose, or the first probabilistic interpreter.**

The measurement justifies it and `ADR-0103` requires the justification to be
genuine rather than convenient. **It is genuine**: the deterministic ceiling was
measured, and the thing it cannot reach — abstracting eight test cases into one
invariant, reading a guarantee out of prose — is precisely what makes the
difference between 315 transcriptions and 7 concepts.

The honest experiment to run first: **authorize far more of the candidate model
and re-run the plan.** If the plan improves with coverage alone, the abstraction
problem is smaller than it looks. If it does not, the case for interpretation is
stronger than this session could make it.
